01 · Teoria

Conceitos Fundamentais de IoT

A Internet das Coisas (IoT) é uma rede de objectos físicos equipados com sensores, software e conectividade, que comunicam dados sem intervenção humana directa (ISO/IEC 30141:2018 — IoT Reference Architecture).

Exemplos de dispositivos

Câmeras de segurança IP Smartwatches / pulseiras fitness Sensores domésticos (temp., portas, luzes) Assistentes virtuais (Alexa, Google Home)

Características principais

Conectividade constante Geração contínua de dados Processamento distribuído Interoperabilidade entre dispositivos

02 · Teoria + Simulador

Protocolos IoT

Os protocolos de comunicação são fundamentais para a investigação forense em dispositivos IoT: compreendê-los permite identificar, capturar e analisar correctamente o tráfego de rede, preservando a evidência digital.

ProtocoloCaracterísticasAplicação forense
MQTT
Message Queuing Telemetry Transport		Leve, modelo publish/subscribe, ideal para sensoresAnálise de tópicos e mensagens em brokers
CoAP
Constrained Application Protocol		RESTful, para dispositivos limitados, usa UDPExtracção de comandos e respostas
RTSP
Real Time Streaming Protocol		Streaming de vídeo, usado por câmeras IPCaptura de fluxos de vídeo e áudio

Simulador MQTT: publish / subscribe

Um "sensor" publica numa mensagem num tópico; um "investigador" que subscreveu esse tópico (ligado ao broker, como fazes com mosquitto_sub) recebe a mensagem em texto simples — exactamente como seria visto no Wireshark sem TLS. Subscreve um tópico, publica mensagens noutros, e repara no que chega ao feed.

Experimenta publicar em casa/sala/temperatura sem estar subscrito — repara que o feed não recebe nada: é exactamente isso que torna a captura de pacotes (não apenas a subscrição) necessária numa investigação.

mqtt_traffic.pcap — feed do broker (texto simples, sem TLS)

03 · Teoria + Quiz

Riscos e Ameaças na IoT

Principais vulnerabilidades

  • Firmware desactualizado
  • Uso de senhas padrão (ex.: admin/admin)
  • Falta de criptografia na comunicação
  • Portas de rede expostas desnecessariamente

Ataques reais

Botnet Mirai (2016–2025): compromete câmaras IoT e routers (muitas vezes via senhas padrão) para ataques DDoS massivos.

Eavesdropping: interceptação de dados sensíveis transmitidos sem TLS — o mesmo princípio que viste no simulador MQTT acima.

Riscos forenses específicos

Logs voláteis, facilmente sobrescritos Cadeia de custódia comprometida (multi-fabricante) Difícil preservar evidência em tempo real

Exercício: vulnerabilidade → risco forense

Para cada vulnerabilidade, escolhe a consequência forense mais directa.

Forense em Dispositivos Móveis

Objectivo: identificar e preservar dados de smartphones (Android, iOS) para investigações forenses.

TipoDescriçãoExemplo

06 · Prática + Construtor de filtros

Captura e Extracção IoT

Captura de tráfego

Configura mirroring na rede IoT (switch / SPAN port) e utiliza Wireshark ou tcpdump:

sudo tcpdump -i wlan0 -w iot_stream.pcap

A captura deve ser realizada por períodos prolongados para identificar padrões de comunicação.

Extracção de dados

Usa binwalk ou foremost para extrair firmware; analisa metadados e cabeçalhos HTTP com tshark.

Construtor de filtros Wireshark

Para cada situação, escolhe o filtro de exibição correcto entre as opções.

07 · Teoria + Cenários

Ética e Boas Práticas

Boas práticas

  • Usa write blockers para evitar alterações nos dados originais
  • Calcula hashes (MD5, SHA256) para validar integridade
  • Regista todos os passos — data, hora, operador, ferramentas
  • Mantém cópias de segurança das evidências recolhidas

Princípios éticos

  • Respeita a privacidade: obtém mandado ou consentimento explícito
  • Evita examinar dados pessoais não relacionados com o caso
  • Mantém confidencialidade sobre informação sensível
  • Sê transparente sobre métodos e limitações da análise

Falhas éticas podem invalidar provas — ISO/IEC 27037:2012 (Guidelines for identification, collection, acquisition and preservation of digital evidence).
